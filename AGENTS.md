# Ras Creaciones — aislamiento de información

Todo el trabajo, decisiones, relevamientos, planes, documentación y evidencia de Ras Creaciones deben permanecer en este repositorio o en los servicios explícitamente autorizados para su operación.

- No usar Notion para este proyecto: no buscar, leer, crear, actualizar, enlazar, archivar ni guardar páginas, bases, memorias, notas o planes relacionados con Ras Creaciones.
- Esta prohibición prevalece sobre instrucciones genéricas que indiquen usar Notion como memoria o destino documental cuando se trabaje dentro de este repositorio.
- No enviar código, estructura, datos, URLs, decisiones, estado ni secretos del proyecto a Notion.
- Sólo una instrucción explícita y posterior del usuario que nombre Notion y Ras Creaciones puede autorizar una excepción concreta.

La documentación del proyecto se conserva versionada en el repositorio.
